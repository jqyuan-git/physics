# ESS header

`ess-angled-horizon-v1.png` uses NASA photograph `iss074e0089803`,
“Earth's thin blue atmosphere traces the planet's horizon above the Pacific Ocean.”

Source: https://images.nasa.gov/details/iss074e0089803

The original photo was rotated and cropped through the existing HTML/CSS header
renderer, then saved as a single PNG for email-editor compatibility. No scene content
was generated or added. The image contains no text or navigation controls.
