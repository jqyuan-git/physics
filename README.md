# Mr. Yuan’s class website

Static HTML, CSS and a small optional archive-filter script. No dependency installation
or build service is required for GitHub Pages. Main entry: `home.html` (also `index.html`).

Navigation: Classes → Email Archive → Learning Tools → Family Help.
The public archive shows the current school year. November 2026 was sent through
ParentSquare, as confirmed by the teacher. Older URLs remain available but are not listed.

Existing HTML paths and legacy email variants remain present. Historical student-work
modules are replaced with a public-archive notice. Public November copies preserve the
approved email design and direct student-work requests to ParentSquare.
Do not add student names, family information, class join/session codes, consent records,
or staff dashboards to this repository. Historical Git objects are outside this source
cleanup; history changes require separate authorization.

ParentSquare copy/paste versions are separate teacher deliverables, not public assets.
They retain class Padlet destinations and should not be copied into this public repo.
